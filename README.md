# Sudo Render · CI4321 · Tarea 01

Proyecto de Computación Gráfica I con TypeScript y WebGL2.

## Integrantes

- Baudilio Velasquez - 18-10665
- Luis Isea - 19-10175

## Requisitos

- Node.js 20.19 o posterior de la rama 20, o Node.js 22.12 o posterior.
- npm.
- Navegador con soporte para WebGL2.

## Ejecución

```bash
git clone https://github.com/baudiliovm/sudo_render_tarea01_ci4321.git
cd sudo_render_tarea01_ci4321
npm ci
npm run dev
```

Abrir la dirección local indicada en la terminal.

## Compilación

```bash
npm run build
npm run preview
```

`build` comprueba TypeScript y genera la aplicación en `dist/`.
`preview` sirve la aplicación compilada para revisarla en el navegador.
